## 💻 Sobre el Proyecto
TuFit 360 es una página web multipágina (MPA) diseñada para un servicio profesional de preparación física integral. El objetivo del proyecto es ofrecer una experiencia de usuario clara y directa para deportistas que buscan mejorar su rendimiento mediante trabajos de fuerza, velocidad, resistencia y prevención de lesiones.

Este proyecto ha sido desarrollado desde cero, aplicando buenas prácticas de maquetación estructurada, diseño responsive y estilos modernos sin depender de frameworks externos.

## 🚀 Características Principales
- **Arquitectura Multipágina (MPA):** Navegación fluida e intuitiva dividida por servicios, tarifas y equipo.
- **Diseño Responsive:** Adaptabilidad total a dispositivos móviles, tablets y escritorio mediante Media Queries y Flexbox/CSS Grid.
- **UI/UX Orientado a la Conversión:** Llamadas a la acción (CTAs) estratégicas, visualización clara de planes de precios (destacando descuentos) y enlaces directos a WhatsApp.
- **Componentes Dinámicos:** Integración de un sistema de Preguntas Frecuentes (FAQ) utilizando etiquetas semánticas de HTML5 (`<details>` y `<summary>`).
- **Integración de Mapas:** Visualización de las instalaciones (Campo Municipal Vinyets-Molí-Vell) mediante un iframe interactivo de Google Maps.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica, accesibilidad y SEO básico.
- **CSS3:** Maquetación con Flexbox y Grid, variables CSS para la paleta de colores corporativa y diseño adaptativo.
- **JavaScript (Vanilla):** Funcionalidad básica para la carga dinámica de elementos (si aplica).
- **Git & GitHub:** Control de versiones y despliegue del proyecto.
